# CardioLens Data Card

## Summary and status

The bundled file `data/z_alizadeh_sani_dataset.csv` contains 303 records and 54 columns. It is classified as **synthetic demonstration data** because every row exactly reproduces this project's deterministic generator with `n_samples=303` and `random_state=42`. The filename and UCI-like schema do not prove that these are authentic clinical records. No independent clinical source, dataset license, or access date is established. Do not cite or describe this file as the original Z-Alizadeh Sani dataset.

SHA-256: `4b6e0a08d400a4b113344e5ed56036688d0576abcf3462fab486558ea339c153`.

## Intended use and prohibited interpretation

The dataset supports software development and demonstration only. It is not suitable for diagnosis, treatment, triage, clinical research conclusions, or estimating real-world disease risk. Synthetic outcomes are generated by rules and are not clinically adjudicated.

## Structure and targets

The dataset has 303 rows, 54 columns, zero exact duplicate rows, and zero missing cells in the bundled generated copy. The feature-like fields span age, sex, anthropometrics, history, symptoms, laboratory values, ECG indicators, and echocardiography-like fields. The CSV contains `CAD`, `LAD`, `LCX`, `RCA`, and `Cath` outcome/downstream columns; all five are excluded from model input features. The four binary targets are the generator's CAD, LAD, LCX, and RCA labels. Their clinical thresholds and meaning are not verified; there is no authentic target adjudication or dictionary.

Bundled class counts: CAD 216 positive / 87 negative; LAD 166 / 137; LCX 105 / 198; RCA 115 / 188. These are properties of the synthetic generator, not population prevalence.

## Processing and modeling

Numerical features receive median imputation and scaling; categorical features receive mode imputation and one-hot encoding. These transforms are fitted inside each stratified training fold. `CAD`, `Cath`, `LAD`, `LCX`, and `RCA` are excluded from predictors. Candidate estimators are compared per target using pooled out-of-fold F1; reported metrics use those same pooled predictions and can be optimistic. The selected estimator is refit on all 303 records for demonstration inference. No independent held-out cohort, calibration, external validation, or confidence interval is available.

## Known risks and limitations

- Synthetic feature/outcome relationships do not establish clinical validity.
- The schema and generator cannot establish measurement units or authentic clinical semantics for all fields.
- A row-level duplicate check does not establish unique patients or independence.
- Derived or post-diagnosis leakage beyond explicitly excluded outcome columns cannot be adjudicated without a source data dictionary.
- Model probabilities have not been calibrated or externally validated.
- The 3D display is schematic and not derived from these records or from patient imaging.

## Reproduction

Run `python -m ml.train` from the repository root. The training pipeline checks whether the bundled CSV matches the seeded generator, records the source hash and evaluation details in `models/metrics.json`, and does not replace the CSV. See `docs/ML_PIPELINE.md` and `docs/ML_EVALUATION.md`.
